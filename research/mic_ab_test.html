Microphone A/B test

Say the same sentence each time, at the same distance from the microphone, for example "paani nahi aa raha hai". Record each setting twice. Each recording downloads automatically as a mic_<setting>_<n>.webm file. Then tell Claude the sentence you said.

Serve this page from localhost (microphone access needs it): python -m http.server 8765 in the research folder, then open http://localhost:8765/mic_ab_test.html.
