# data/

`complaints.csv` is a **synthetic starter dataset**, written by Claude and generated by `build_dataset.py`. Regenerate it with `python data/build_dataset.py`.

| Column | Meaning |
|---|---|
| id | Row id |
| text | The complaint |
| language | `en`, `hinglish` (Roman script) or `hi` (Devanagari) |
| department | Intended department (7 classes, including `Unclear`) |
| group_id | Same complaint in all languages and its variant share one group |
| split | `train` / `calibration` / `test` (50% / 25% / 25%) |
| is_variant | 1 if a longer version of a base complaint |
| source | `synthetic` |

## What this data is good for
Developing and debugging the pipeline: running the classifier, the confidence methods, the router and the plots end to end.

## What it is NOT good for
**Do not report results from it as the project's findings.**
- The labels are the generator's intent, not two independent human labellers, so there is no agreement score.
- The text is clean, regular and written by one author. Real complaints are messier, which makes scores here optimistic.
- Variants are near-duplicates of base complaints. For a stricter test, filter to `is_variant == 0`.

The synopsis needs 400-600 real complaints from public portals, labelled by two people. Replace or extend this file with them (same columns, `source` = portal name) and rerun the split.
